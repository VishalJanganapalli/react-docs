React Day 3 Notes: Props, Lists, and Keys

1. What are Props?
Props (Properties) are used to pass data from a parent component to a child component.
Think of props like function arguments.

Real-Life Example
Imagine a Student ID Card.
The card design is the same, but the data changes:
Student 1 → Rahul
Student 2 → Priya 
Student 3 → Arjun

Instead of creating separate components, we pass different data using props.

Props are Read-Only (Very Important)

Basic Props Example
function User(props) {
  return <h1>Hello {props.name}</h1>;
}
function App() {
  return (
    <>
      <User name="Rahul" />
      <User name="Priya" />
      <User name="Arjun" />
    </>
  );
}
Output
Hello Rahul
Hello Priya
Hello Arjun

Explanation
<User name="Rahul" />
creates:
props = {
  name: "Rahul"
}
Inside the component:
props.name
becomes:
Rahul


2. Passing Strings Through Props
function User(props) {
  return <h2>{props.name}</h2>;
}
function App() {
  return (
    <>
      <User name="Rahul" />
      <User name="Priya" />
    </>
  );
}
Output
Rahul
Priya

3. Passing Numbers Through Props
function Student(props) {
  return (
    <h2>
      {props.name} - Age: {props.age}
    </h2>
  );
}
function App() {
  return (
    <>
      <Student name="Rahul" age={22} />
      <Student name="Priya" age={21} />
    </>
  );
}
Output
Rahul - Age: 22
Priya - Age: 21
Note
Numbers use curly braces:
age={22}
Not:
age="22"

4. Passing Boolean Values
function User(props) {
  return (
    <h2>
      {props.name} - Active: {props.isActive ? "Yes" : "No"}
    </h2>
  );
}
function App() {
  return (
    <>
      <User name="Rahul" isActive={true} />
      <User name="Priya" isActive={false} />
    </>
  );
}
Output
Rahul - Active: Yes
Priya - Active: No


Default Props / Default Values
Sometimes a prop isn't passed.

function User({ name = "Guest" }) {
  return <h1>Hello {name}</h1>;
}

function App() {
  return <User />;
}


5. Passing Multiple Props
function Employee(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <p>Age: {props.age}</p>
      <p>Role: {props.role}</p>
    </div>
  );
}
function App() {
  return (
    <Employee
      name="Rahul"
      age={24}
      role="Developer"
    />
  );
}

6. Destructuring Props
Instead of writing:
props.name
props.age
props.role
Use destructuring:
function Employee({ name, age, role }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{age}</p>
      <p>{role}</p>
    </div>
  );
}
This is the most common React style.

7. Passing Objects Through Props
Parent Component
function App() {
  const student = {
    name: "Rahul",
    age: 22,
    city: "Hyderabad"
  };
  return <Student data={student} />;
}
Child Component
function Student(props) {
  return (
    <>
      <h2>{props.data.name}</h2>
      <p>{props.data.age}</p>
      <p>{props.data.city}</p>
    </>
  );
}
Output
Rahul
22
Hyderabad

8. Passing Arrays Through Props
Parent
function App() {
  const skills = [
    "HTML",
    "CSS",
    "JavaScript",
    "React"
  ];
  return <Skills data={skills} />;
}
Child
function Skills(props) {
  return (
    <>
      {props.data.map((skill) => (
        <p>{skill}</p>
      ))}
    </>
  );
}
Output
HTML
CSS
JavaScript
React

9. What is map()?
map() is used to loop through arrays and return JSX.
Normal JavaScript
const nums = [1, 2, 3];
nums.map((num) => {
  console.log(num);
});
Output:
1
2
3
React Example
const fruits = [
  "Apple",
  "Banana",
  "Orange"
];
function App() {
  return (
    <ul>
      {fruits.map((fruit) => (
        <li>{fruit}</li>
      ))}
    </ul>
  );
}
Output
• Apple
• Banana
• Orange

10. map() With Index
const fruits = [
  "Apple",
  "Banana",
  "Orange"
];
function App() {
  return (
    <>
      {fruits.map((fruit, index) => (
        <h2>
          {index + 1}. {fruit}
        </h2>
      ))}
    </>
  );
}
Output
1. Apple
2. Banana
3. Orange

12. What are Keys?
Keys help React identify which item changed, added, or removed.
Without keys:
{fruits.map((fruit) => (
  <li>{fruit}</li>
))}
React warning:
Each child in a list should have a unique key prop
Correct Usage
{fruits.map((fruit, index) => (
  <li key={index}>
    {fruit}
  </li>
))}
Better Usage
Instead of index:
const students = [
  {
    id: 101,
    name: "Rahul"
  },
  {
    id: 102,
    name: "Priya"
  }
];
Use:
{students.map((student) => (
  <h2 key={student.id}>
    {student.name}
  </h2>
))}
Why?
IDs remain stable.
Indexes may change when items are inserted or deleted.

13. Mini Project - Student Card
Step 1: Data
const students = [
  {
    id: 1,
    name: "Rahul",
    age: 22,
    course: "React"
  },
  {
    id: 2,
    name: "Priya",
    age: 21,
    course: "Node"
  },
  {
    id: 3,
    name: "Arjun",
    age: 23,
    course: "Python"
  }
];
Step 2: StudentCard Component
function StudentCard(props) {
  return (
    <div>
      <h2>{props.name}</h2>
      <p>Age: {props.age}</p>
      <p>Course: {props.course}</p>
    </div>
  );
}
Step 3: Render Cards
function App() {
  return (
    <>
      {students.map((student) => (
        <StudentCard
          key={student.id}
          name={student.name}
          age={student.age}
          course={student.course}
        />
      ))}
    </>
  );
}

14. Better Version Using Object Prop
Pass complete object:
<StudentCard
  key={student.id}
  student={student}
/>
Component:
function StudentCard({ student }) {
  return (
    <div>
      <h2>{student.name}</h2>
      <p>{student.age}</p>
      <p>{student.course}</p>
    </div>
  );
}
This is commonly used in real projects.
