REACT - DAY 5: FORM SUBMISSION AND API ERRORS

The Day 5 Forms & Validation notes cover controlled inputs, form fields, and
client-side validation. This note focuses on submitting valid form data and
showing the result of a server request.

============================================================
1. FORM SUBMISSION FLOW
============================================================

1. The user enters data in controlled inputs.
2. The submit handler receives the form event.
3. Call preventDefault() to stop a full page reload.
4. Send the data to the server.
5. Show a loading, success, or error message.

Use required and an appropriate input type for basic browser checks. The
server must still validate submitted data.

============================================================
2. HANDLING SERVER AND NETWORK ERRORS
============================================================

Validation errors happen when input does not meet the form's rules. The
Forms & Validation notes explain how to show these next to fields.

When submitting to a server, also handle:

- Server/API errors, such as a rejected email or a server failure.
- Network errors, when the browser cannot reach the server.
- Loading state, so the user knows the request is in progress.

============================================================
3. COMPLETE SUBMISSION EXAMPLE
============================================================

import { useState } from "react";

function RegistrationForm() {
  const [email, setEmail] = useState("");
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState("");
  const [success, setSuccess] = useState("");

  async function handleSubmit(event) {
    event.preventDefault();
    setError("");
    setSuccess("");
    setLoading(true);

    try {
      const response = await fetch("/api/register", {
        method: "POST",
        headers: {
          "Content-Type": "application/json"
        },
        body: JSON.stringify({ email })
      });

      if (!response.ok) {
        throw new Error(`Registration failed (${response.status}).`);
      }

      setSuccess("Registration successful.");
      setEmail("");
    } catch (requestError) {
      const message = requestError instanceof Error
        ? requestError.message
        : "Could not submit the form.";
      setError(message);
    } finally {
      setLoading(false);
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="email">Email</label>
      <input
        id="email"
        type="email"
        value={email}
        onChange={(event) => setEmail(event.target.value)}
        required
      />

      {error && <p role="alert">{error}</p>}
      {success && <p role="status">{success}</p>}

      <button type="submit" disabled={loading}>
        {loading ? "Submitting..." : "Register"}
      </button>
    </form>
  );
}

Replace /api/register with an endpoint provided by your backend. The example
does not replace client-side validation; validate the data on the server too.
