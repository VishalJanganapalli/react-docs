REACT - DAY 6: FORM VALIDATION

This lesson continues the controlled form examples from Day 5. We will add
simple validation and show an error when an input needs to be fixed.

The examples use one form component and local state. They do not need custom
components or props.

============================================================
1. REQUIRED FIELDS
============================================================

Check text fields before submitting. Use trim() so spaces alone are treated as
an empty value.

The required attribute marks an input as required in the HTML. In the complete
example, noValidate lets React show the messages in a consistent place.

============================================================
2. EMAIL AND PASSWORD CHECKS
============================================================

Use type="email" for an email input. A simple pattern can catch common typing
mistakes, but it does not prove that the email address exists.

For this beginner example, the password must have at least six characters.
Applications can choose different rules. Password checks in the browser are
only for user feedback; important checks must also happen on the server.

============================================================
3. CONDITIONAL VALIDATION
============================================================

Some inputs are only required for certain choices. In this example, ask for a
company name only when the user chooses a Company account.

The company-name input is shown only when the Company option is selected.

============================================================
4. SHOWING ERROR MESSAGES
============================================================

Keep error messages in state. Show each message beside its input and stop
submission when the errors object contains any messages.

The complete example below checks all fields when the user submits the form.

============================================================
5. COMPLETE FORM EXAMPLE
============================================================

import { useState } from "react";

const emailPattern = /^\S+@\S+\.\S+$/;

function RegistrationForm() {
  const [name, setName] = useState("");
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [confirmPassword, setConfirmPassword] = useState("");
  const [accountType, setAccountType] = useState("personal");
  const [companyName, setCompanyName] = useState("");
  const [errors, setErrors] = useState({});
  const [submitted, setSubmitted] = useState(false);

  function handleSubmit(event) {
    event.preventDefault();

    const nextErrors = {};

    if (!name.trim()) {
      nextErrors.name = "Name is required.";
    }

    if (!email.trim()) {
      nextErrors.email = "Email is required.";
    } else if (!emailPattern.test(email.trim())) {
      nextErrors.email = "Enter a valid email address.";
    }

    if (!password) {
      nextErrors.password = "Password is required.";
    } else if (password.length < 6) {
      nextErrors.password = "Password must be at least 6 characters.";
    }

    if (!confirmPassword) {
      nextErrors.confirmPassword = "Please confirm your password.";
    } else if (confirmPassword !== password) {
      nextErrors.confirmPassword = "Passwords do not match.";
    }

    if (accountType === "company" && !companyName.trim()) {
      nextErrors.companyName = "Company name is required.";
    }

    setErrors(nextErrors);
    setSubmitted(Object.keys(nextErrors).length === 0);
  }

  return (
    <form onSubmit={handleSubmit} noValidate>
      <div>
        <label htmlFor="name">Name</label>
        <input
          id="name"
          type="text"
          value={name}
          onChange={(event) => {
            setName(event.target.value);
            setSubmitted(false);
          }}
          required
        />
        {errors.name && <p>{errors.name}</p>}
      </div>

      <div>
        <label htmlFor="email">Email</label>
        <input
          id="email"
          type="email"
          value={email}
          onChange={(event) => {
            setEmail(event.target.value);
            setSubmitted(false);
          }}
          required
        />
        {errors.email && <p>{errors.email}</p>}
      </div>

      <div>
        <label htmlFor="password">Password</label>
        <input
          id="password"
          type="password"
          value={password}
          onChange={(event) => {
            setPassword(event.target.value);
            setSubmitted(false);
          }}
          required
        />
        {errors.password && <p>{errors.password}</p>}
      </div>

      <div>
        <label htmlFor="confirmPassword">Confirm password</label>
        <input
          id="confirmPassword"
          type="password"
          value={confirmPassword}
          onChange={(event) => {
            setConfirmPassword(event.target.value);
            setSubmitted(false);
          }}
          required
        />
        {errors.confirmPassword && <p>{errors.confirmPassword}</p>}
      </div>

      <div>
        <label htmlFor="accountType">Account type</label>
        <select
          id="accountType"
          value={accountType}
          onChange={(event) => {
            setAccountType(event.target.value);
            setCompanyName("");
            setErrors((current) => ({ ...current, companyName: "" }));
            setSubmitted(false);
          }}
        >
          <option value="personal">Personal</option>
          <option value="company">Company</option>
        </select>
      </div>

      {accountType === "company" && (
        <div>
          <label htmlFor="companyName">Company name</label>
          <input
            id="companyName"
            type="text"
            value={companyName}
            onChange={(event) => {
              setCompanyName(event.target.value);
              setSubmitted(false);
            }}
            required
          />
          {errors.companyName && <p>{errors.companyName}</p>}
        </div>
      )}

      <button type="submit">Register</button>

      {Object.keys(errors).length > 0 && (
        <p role="alert">Please fix the fields with errors.</p>
      )}
      {submitted && <p>Form is valid and ready to submit.</p>}
    </form>
  );
}

============================================================
DAY 6 SUMMARY
============================================================

- Check required fields before submitting.
- Check that the email looks valid.
- Check password length and confirm that both passwords match.
- Show or require a field based on the user's selection.
- Display a clear message when a field is invalid.
- Validate important data on the server too.
