Recommended Rules
components/: Shared, reusable UI (buttons, modals, tables, inputs).
features/: Domain-specific code (auth, products, users). Keep components, hooks, services, and utilities that are only used by that feature here.
pages/: Route-level components that assemble features and shared components.
hooks/: Global reusable custom hooks.
services/: Shared API clients and cross-feature services.
utils/: Pure helper functions with no React dependencies.
constants/: Static values, routes, regex patterns, roles, and messages.
config/: Application configuration (environment, Axios setup, theme).
store/: Global state management (Redux Toolkit, Zustand setup, etc.).
context/: React Context providers when needed.

| Folder                | Contains                                                                   |
| --------------------- | -------------------------------------------------------------------------- |
| **assets**            | Images, icons, fonts, global styles                                        |
| **components/ui**     | Small reusable UI elements (Button, Card, Input, Modal, Loader)            |
| **components/layout** | Layout components (Navbar, Sidebar, Footer, Header)                        |
| **components/common** | Shared functionality (Pagination, SearchBar, ProtectedRoute, ErrorMessage) |
| **pages**             | Route-level pages and components used only by that page                    |
| **hooks**             | Reusable custom hooks                                                      |
| **services**          | API calls and Axios configuration                                          |
| **context**           | React Context providers                                                    |
| **utils**             | Helper functions                                                           |
| **constants**         | Static values and application constants                                    |
| **routes**            | React Router configuration                                                 |
| **config**            | App configuration (Axios instance, environment settings)                   |
