REACT ROUTING
=========================================

WHAT IS ROUTING?

Routing is the process of navigating between different pages or views in a React application without reloading the entire web page.
React applications are called Single Page Applications (SPA). 
Instead of loading a new HTML page every time, React updates only the required components.

Example URLs:

/                 -> Home Page
/about            -> About Page
/contact          -> Contact Page
/products         -> Products Page
/profile          -> Profile Page

Each URL displays a different React component.

-----------------------------------------

WHY DO WE NEED ROUTING?

Without routing:

• Everything would appear on one page.
• Navigation becomes difficult.
• Browser Back button won't work properly.
• URLs cannot be shared easily.
• Users cannot bookmark pages.

With routing:

• Different pages have different URLs.
• Navigation is faster.
• No full page refresh.
• Better user experience.
• Browser history works correctly.

STEP 1 : BrowserRouter

main.jsx

import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

import { BrowserRouter } from "react-router-dom";

ReactDOM.createRoot(document.getElementById("root")).render(

<BrowserRouter>
<App />
</BrowserRouter>

);

BrowserRouter enables routing using the browser's History API.

Responsibilities:

• Stores browser history
• Changes URL
• Supports Back button
• Supports Forward button
• Updates components based on URL

-----------------------------------------

STEP 2 : Create Routes

App.jsx

import { Routes, Route } from "react-router-dom";

function App(){
    return(
        <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/about" element={<About />} />
            <Route path="/contact" element={<Contact />} />
        </Routes>
    );
}

-----------------------------------------

ROUTE COMPONENT

Syntax

<Route path="/about" element={<About />} />

path - Specifies URL.
element - Specifies which component should render.

Example
URL - /about
↓
Component - <About />

-----------------------------------------

LINK COMPONENT

Instead of using <a href="/about">about</a>

Use
import { Link } from "react-router-dom";

<Link to="/about">About</Link>

Why?

Anchor tag reloads the entire page.
Link changes URL without refreshing.

-----------------------------------------

NAVLINK

NavLink works like Link.

Difference:

NavLink knows which route is active.

Example

import { NavLink } from "react-router-dom";

<NavLink to="/about"> About </NavLink>

-----------------------------------------

ACTIVE NAVLINK

<NavLink to="/about" className={({isActive})=> isActive ? "active" : "" } > About </NavLink>

If About page is active CSS class active will be added automatically.

-----------------------------------------

COMMON NAVBAR

import { Link } from "react-router-dom";

function Navbar(){
    return(
        <nav>
            <Link to="/">Home</Link>
            <Link to="/about">About</Link>
            <Link to="/contact">Contact</Link>
        </nav>
    );
}

-----------------------------------------

404 PAGE

* means - Match every unknown URL.

Example

/random
/hello
/testing

will display - NotFound Component

-----------------------------------------

PROGRAMMATIC NAVIGATION

useNavigate()

import { useNavigate } from "react-router-dom";

navigate("/about");

Moves user to About page.

Go Back - navigate(-1);

Go Forward - navigate(1);

NESTED ROUTES

Nested routing allows one route to contain child routes.

Example Structure

Dashboard
|
|-- Profile
|
|-- Settings
|
|-- Users

URLS

/dashboard
/dashboard/profile
/dashboard/settings
/dashboard/users

-----------------------------------------

CREATING NESTED ROUTES

import { Routes, Route } from "react-router-dom";

<Routes>
    <Route path="/dashboard" element={<Dashboard />} >
        <Route path="profile" element={<Profile />} />
        <Route path="settings" element={<Settings />} />
        <Route path="users" element={<Users />} />
    </Route>
</Routes>

Notice:

Child paths DO NOT start with "/"

Correct - profile, settings, users,
Incorrect /profile, /settings, /users

-----------------------------------------

OUTLET

Nested routes require Outlet.

Example

import { Outlet } from "react-router-dom";

function Dashboard(){

return(

<>

<h1>Dashboard</h1>

<Outlet />

</>

);

}

Outlet displays child routes.
Without Outlet Child routes will never appear.

PROTECTED ROUTES

Protected routes allow only authenticated users to access certain pages.

Example

import { Navigate } from "react-router-dom";

function ProtectedRoute({ children }) {
  const isLoggedIn = true;
  return isLoggedIn ? children : <Navigate to="/login" replace />;
}

-----------------------------------------

USING PROTECTED ROUTES

<Route path="/dashboard" element={<ProtectedRoute><Dashboard /></ProtectedRoute>} />

If the user is logged in, Dashboard is displayed.
Otherwise, the user is redirected to the Login page.

-----------------------------------------

ROLE BASED PROTECTED ROUTES

function AdminRoute({ children }) {
  const user = { role: "admin" };
  return user.role === "admin"
    ? children
    : <Navigate to="/unauthorized" replace />;
}

Usage

<Route path="/admin" element={<AdminRoute><AdminPanel /></AdminRoute>} />

-----------------------------------------

REDIRECTING USERS

Navigate component redirects users.

<Route path="/old-about" element={<Navigate to="/about" replace />} />

Visiting

/old-about

Automatically redirects to

/about

PROGRAMMATIC REDIRECT

import { useNavigate } from "react-router-dom";

function Login() {

LAZY LOADING

Large applications should not load every page initially.

Instead, load pages only when required.

-----------------------------------------

IMPORTING LAZY COMPONENTS

import { lazy } from "react";

const Home = lazy(() => import("./Home"));
const About = lazy(() => import("./About"));
const Contact = lazy(() => import("./Contact"));

-----------------------------------------

SUSPENSE

import { Suspense } from "react";

<Suspense fallback={<h2>Loading...</h2>}>
  <Home />
</Suspense>

fallback displays a loading UI until the component finishes loading.

-----------------------------------------

LAZY ROUTES

<Route path="/" element={<Suspense fallback={<h2>Loading...</h2>}><Home /></Suspense>} />

<Route path="/about" element={<Suspense fallback={<h2>Loading...</h2>}><About /></Suspense>} />

<Route path="/contact" element={<Suspense fallback={<h2>Loading...</h2>}><Contact /></Suspense>} />

-----------------------------------------

WHY LAZY LOADING?

Advantages

• Faster initial loading
• Smaller JavaScript bundle
• Better performance
• Loads only the required page
• Improves user experience

-----------------------------------------

MODERN ROUTING

React Router recommends using createBrowserRouter() for new applications.

-----------------------------------------

CREATING ROUTER

import { createBrowserRouter } from "react-router-dom";

const router = createBrowserRouter([
  { path: "/", element: <Home /> },
  { path: "/about", element: <About /> },
  { path: "/contact", element: <Contact /> }
]);

-----------------------------------------

ROUTER PROVIDER

import { RouterProvider } from "react-router-dom";

<RouterProvider router={router} />

RouterProvider replaces BrowserRouter when using the Data Router API.

-----------------------------------------

ROUTE OBJECTS

Instead of writing

<Route path="/" element={<Home />} />

You can write

{
  path: "/",
  element: <Home />
}

Each object represents one route.

-----------------------------------------

LOADERS

Loaders fetch data before rendering a page.

import { createBrowserRouter } from "react-router-dom";

const router = createBrowserRouter([
  {
    path: "/users",
    element: <Users />,
    loader: async () => {
      return fetch("/api/users");
    }
  }
]);

-----------------------------------------

READING LOADER DATA

import { useLoaderData } from "react-router-dom";

function Users() {
  const users = useLoaderData();

  return (
    <div>
      {JSON.stringify(users)}
    </div>
  );
}

-----------------------------------------

WHY USE LOADERS?

Advantages

• Fetch data before rendering
• Avoid unnecessary loading states
• Keep routing and data together
• Better performance

-----------------------------------------

ACTIONS

Actions handle form submissions.

const router = createBrowserRouter([
  {
    path: "/contact",
    element: <Contact />,
    action: async ({ request }) => {
      const formData = await request.formData();
      return formData;
    }
  }
]);

-----------------------------------------

FORM COMPONENT

import { Form } from "react-router-dom";

<Form method="post">
  <input type="text" name="username" />
  <button type="submit">Submit</button>
</Form>

Submitting the form automatically calls the route action.

-----------------------------------------

ERROR BOUNDARIES

Handle route-specific errors.

const router = createBrowserRouter([
  {
    path: "/",
    element: <Home />,
    errorElement: <ErrorPage />
  }
]);

-----------------------------------------

READ ROUTE ERRORS

import { useRouteError } from "react-router-dom";

function ErrorPage() {
  const error = useRouteError();

  return <h2>{error.statusText}</h2>;
}

-----------------------------------------

WHEN ERROR BOUNDARIES RUN

• Loader throws an error
• Action throws an error
• Route rendering fails
• Resource is not found
